FAQ

Frequently asked questions

Does this frontend download real videos by itself?

No. Browsers cannot reliably process every platform directly. This project includes a polished mock/demo flow and an API integration layer. Connect it to your own authorized backend service.

Which platforms are supported?

The UI validates common YouTube, Facebook, TikTok, Instagram, and X/Twitter links. Your actual backend determines which platforms and formats are available.

Can I add more resolutions or formats?

Yes. The options are rendered dynamically from the API response, so your backend can return 4K, 1440p, WebM, AAC, M4A, or other formats if permitted.

Is it okay to download any online video?

Download only content you own, have permission to use, or that is otherwise legally downloadable. Also follow the relevant platform terms and local law.
